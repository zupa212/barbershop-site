# King's Hair and Nails Salon — Photos

Βάλε εδώ μέσα τις φωτογραφίες του salon (μαλλιά, νύχια, χώρος, manicure/pedicure, styling).

Υποστηριζόμενες μορφές: `.jpg`, `.jpeg`, `.png`, `.webp`

Όλα τα αρχεία πιάνονται **αυτόματα** στη σελίδα `/kings-hair-and-nails-panorama` (gallery section).
Δεν χρειάζεται να αλλάξεις κώδικα — απλά πρόσθεσε/αφαίρεσε αρχεία.

Συμβουλές για SEO + απόδοση:
- Προτίμα `.webp` ή compressed `.jpg` (≤ 400KB) για γρήγορο load.
- Δώσε περιγραφικά ονόματα αρχείων με ελληνικές παύλες, π.χ. `manicure-panorama.jpg`, `xtenisma-mallia.jpg`, `salon-xwros-1.jpg`. Το όνομα του αρχείου χρησιμοποιείται για το alt text.
